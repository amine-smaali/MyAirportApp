## Getting Started

### Prerequisites

- Java Development Kit (JDK) 8 or higher
- Maven or Gradle (if applicable)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/amine-smaali/MyAirportApp.git
```

2. Navigate to the project directory:
```bash
cd MyAirportApp
```

3. Build the project:
```bash
javac MainActivity.java
```
